# 肥鱼记账

肥鱼记账是一款 Android 8.0（API 26）及以上可用的离线个人记账应用。它支持手动收支、账本筛选、月度等区间统计、通知辅助记账、四套本地主题，以及通过系统文件选择器完成的本地 JSON 备份与恢复。

## 隐私与权限

- 账本、分类、账户、商户规则和设置仅保存在设备本地；应用不提供云同步，也不需要网络权限。
- 应用不申请广泛存储权限。备份导入、导出使用 Android 系统文件选择器（SAF），文件位置由用户选择。
- 自动记账依赖 Android 的“通知使用权”。首次使用时可在首页查看未开启说明，再通过“设置 → 通知读取权限 → 打开系统通知使用权设置”授权。
- 只有在应用内启用的微信、支付宝或精确匹配白名单的银行应用来源才会被处理。关闭来源开关或撤销通知使用权后，不会继续读取该来源的新通知。
- 通知格式由支付应用控制，版本或文案变化可能导致无法识别。信息不完整、方向不明确、转账类或低置信度候选必须进入“待确认”；无法安全解析的格式应留下诊断或被忽略，绝不能静默生成一笔已确认交易。请定期核对账本。
- 通知辅助记账不等同于银行对账，且可能受系统省电策略、进程状态、通知聚合方式和设备厂商限制影响。

## 记账与统计

账单页支持搜索与五个下拉筛选（月份、收支、状态、分类、账户），条件叠加生效；点右上角“批量”进入选择模式，勾选或全选后可一次删除多条记录，删除前会二次确认。

手动记录可以选择支出或收入、分类、账户、日期和备注。启用“内部转账”后，记录仍保留在账本中，但不计入收入、支出、余额或分类统计，避免账户间转移被重复计算。

统计支持日、周、月、年和自选区间，并按支出或收入分别汇总。待确认记录和内部转账不会进入已确认的收支统计。

## 主题

在“设置 → 外观”中可选择“清透薄荷”“小票账本”“纸感极简”或“蓝色肥鱼”。选择后立即生效并保存在本机。默认主题仍是“清透薄荷”，已有偏好不受影响。

四套皮肤各自有一套首页头卡与一套导航图标。前三套全部由 Canvas 绘制，不依赖网络与位图；蓝色肥鱼的装饰仍由 Canvas 绘制，只有右上角的循环贴纸与空记录插画是位图：

| 皮肤 | 首页头卡 | 导航图标语言 |
| --- | --- | --- |
| 清透薄荷 | 薄荷渐层 + 柔光团 + 右上角玻璃圆章徽章 | 圆头描边、实心点缀 |
| 小票账本 | 纸面 + 上下齿孔虚线 + 右上角齿孔纸签徽章 | 直角等宽线、实心色块 |
| 纸感极简 | 米色纸面 + 深绿短竖线 + 右上角墨线标注徽章 | 1.2dp 细线、大量留白 |
| 蓝色肥鱼 | 深海渐变横幅 + 三层浪 + 气泡 + 金星 + 右上角循环贴纸（每页一句台词） | 像素贴纸（点一下播一遍） |

底部导航按皮肤分别换皮（`ui/theme/AppBottomBar.kt`）：清透薄荷是白底圆角浮起 + 淡薄荷胶囊选中，小票账本是小票纸面 + 虚线撕口 + 方框选中，纸感极简是平铺纸面 + 墨色下划线选中。未选中一律画描边，选中的图标换成「实心剪影减去内部细节」的画法（房子挖门洞、账单挖账目行、齿轮挖轴孔），一眼能看出当前页。中央「记一笔」是各皮肤自己的强调色按钮：薄荷/纸感是圆形，小票是方章形。

四页共用同一张头卡（`ThemedHomeHeader(title, subtitle, page)`）：首页写「今天」，账单 / 统计 / 设置各自写页名，装饰语言随皮肤走，四张卡并排是一套。版式上文字列 `weight(1f)` 吃掉剩余宽度、单行省略，右侧徽章钉在固定槽位——纸感极简原先那道竖线是按卡片宽度的 3.5% 定位的，横屏/平板上直接扎进标题第一个字，现在改成跟着文字排版走的 3dp 色块，再宽的屏也压不到字。

前三套皮肤的头卡右上角各有一枚「标注徽章」：平时的呼吸循环（16 帧 × 100ms）点一下播一遍按下动画（弹缩 → 荡开 → 收尾，16 帧共 1.22 秒）再回到循环。徽章里画的不是图标，而是一**件**有材质的小物件，点一下做它自己的动作——图标（太阳 / 单据 / 柱子 / 齿轮）在哪个 App 里都长一样，换成玻璃或纸签只是换了外壳，所以每个页面各配一件：

| 页面 | 清透薄荷（玻璃） | 小票账本（纸、铁皮） | 纸感极简（墨线） |
| --- | --- | --- | --- |
| 今天 | 叶尖露珠（胀大 → 坠落 → 再聚） | 打卡钟（工时卡按进缝隙、表针走到位） | 折角便签（角折下去再展开） |
| 账单 | 玻璃零钱罐（一枚硬币掉进去） | 小票打印机（吐出一截锯齿小票） | 线装账本（右缘一页掀起来） |
| 统计 | 玻璃量杯（液面涨一格、气泡上浮） | 钢笔折线（笔尖自左向右画出上扬线） | 墨线折线（一笔画上去，末点留墨团） |
| 设置 | 薄荷玻璃旋钮（拧过一格、指针弹回） | 铁皮拨杆开关（拨杆拍到另一头、灯亮） | 线上墨点（墨点从一头滑到另一头） |

素材由 `python tools/gen_header_badges.py --preview` 生成到 `assets/header_badge/<skin>_<page>/{idle,tap}/`（12 枚 × 32 帧，96 色量化），`--preview` 会另出一张 3×4 拼图与逐枚 GIF 到 `tools/badge_previews/`（已 gitignore）。每件物件只吃一个参数 `k`（0~1），待机时 `k` 缓慢呼吸、点击时 `k` 走一遍它自己的动作，所以同一套代码既是静帧也是动画。

蓝色肥鱼的头卡右上角是一颗竖版像素贴纸，装在一颗 74dp 的像素气泡里。贴纸四页各一张、各带自己的台词：首页「好运来」、账单「让我看看」、统计「买买买」、设置「安排」（`assets/fish_header/{home,ledger,statistics,settings}/`，帧数 24/24/24/19）。素材是用户给的 GIF，存在 `tools/fish_src/`，`python tools/gen_fish_art.py --stickers` 一次重刷四套：统一取景（按并集包围盒裁、四周留 6% 透明边）、缩到 288px 高，再把底部字幕按亮度做一次双色反相翻成「白填充 + 深墨描边」——深蓝字压在深海渐变上会糊成一片。字幕区域靠「从底往上越过字幕块、再越过一片空行」自动找，找不到空行才退回 0.79 比例兜底。

气泡是用户自己做的两套 432×432 透明 GIF，`tools/gen_fish_bubble.py` 按同一取景切进 `assets/fish_bubble/idle`（16 帧，默认状态循环）和 `tap`（20 帧，触碰时）。平时气泡慢慢转高光，点一下播一遍「触碰时」——鼓一下、碎成水花、再凝聚回原样，播完回到默认循环。贴纸（人物 + 字幕）全程钉在气泡中间：碎的是外面那层泡，人不能跟着消失。空记录插画换成高清版（`res/drawable-nodpi/whale_mascot.png`，768px，抠白底保留围裙与米饭），启动图标换成比赞那张（`tools/gen_fish_art.py` 统一生成四套头卡贴纸、插画与五档图标）。

蓝色肥鱼的底栏用四张像素小图当图标（首页 / 账单 / 统计 / 设置）：白底 26dp 圆角浮起，选中项坐在一颗淡蓝气泡上、标签加粗变蓝，其他项保留原色只降到 88% 不透明度。小图原本是带文字的 GIF，由 `tools/gen_fish_nav.py` 裁掉底部文字、统一留白后切成 120px 逐帧 PNG 放在 `assets/fish_nav/`；点一下导航项就完整播一遍（每帧 80ms，设置那张第 17 帧 240ms），播完停在第一帧，不会自己循环。

## 本地备份与恢复

1. 打开“设置 → 本地备份”。
2. 选择“导出备份”，在系统文件选择器中确定 JSON 文件位置。
3. 恢复时选择“导入备份”并选取有效 JSON 文件。
4. 阅读替换提示，确认后才会用备份中的交易、分类、账户、商户规则和主题替换当前数据。
5. 损坏、格式错误或版本不受支持的文件必须被拒绝，当前数据应保持不变。重要账本请保留多份离线副本，并先在可控设备上验证恢复。
