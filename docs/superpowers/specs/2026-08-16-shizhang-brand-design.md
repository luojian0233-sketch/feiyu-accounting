# 拾账应用名与桌面图标设计

日期：2026-08-16

## 已确认的方向

- 应用显示名称从“自记账”改为“拾账”。
- 图标采用方案 1：一张简洁小票与一条深青色确认勾线。
- 品牌气质为简洁、可靠、轻量；不使用可爱角色、钱币、猪猪存钱罐、计算器、文字或货币符号。

## 目标

让应用在 Android 桌面、最近任务和系统设置中有清晰且一致的识别：名称短、图标在小尺寸下可辨，并与当前青绿、暖白、珊瑚点缀的界面相容。

## 资源设计

1. `@string/app_name` 的值为“拾账”，`application` 通过该资源提供 `label`。
2. 使用 Android 自适应图标资源：圆角暖薄荷底色、暖白小票主体、深青色勾线与一个克制的珊瑚色圆点；前景图形保持在安全区内，系统可以按不同厂商遮罩裁切。
3. 为 Android 8 以下提供同一视觉的矢量回退资源；`icon` 与 `roundIcon` 指向统一启动器资源。
4. 图标采用仓库内 XML 矢量/自适应资源实现，不把生成预览图、截图或外部位图纳入 APK；小票线条和勾线保持清晰，便于日后调整颜色。

## 范围与边界

仅修改应用名称和启动器图标相关资源、Manifest 以及相应的资源合同测试。

不修改：主题配色、应用内页面、快速设置图标、服务名称、权限、依赖、数据库、自动识别、账单数据或备份行为。

## 验收与测试

- JVM/Android 资源合同测试验证 Manifest 的 `label`、`icon`、`roundIcon` 均使用预期资源，且 `app_name` 为“拾账”。
- 编译 Android 测试源码和构建 debug APK，确认资源可打包。
- 真机覆盖安装后，用户在桌面/应用信息中确认名称和图标显示；若系统图标缓存未刷新，说明为启动器缓存，应用内数据不受影响。
- 所有 ADB 命令继续使用 10 秒硬超时；不重启 ADB、不卸载、不清数据。

## 规格自审

无占位项；名称、图标构成、资源形式、兼容回退和验收方式均已明确。范围不包含任何记账功能或敏感数据处理。
