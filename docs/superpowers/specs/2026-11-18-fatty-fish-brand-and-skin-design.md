# 肥鱼记账品牌与肥鱼皮肤设计

日期：2026-11-18
状态：设计（替代 2026-08-16 拾账品牌方案中的应用名与图标部分）

## 目标

1. 应用显示名称改为“肥鱼记账”。
2. 启动器图标改为“大肥鱼”形象：圆胖鱼身、简洁剪影，不出现文字、货币符号或人物。
3. 在“设置 → 外观”中新增一套“蓝色肥鱼”皮肤：以肥鱼元素与清水配色构成的简约界面，不改变现有三套主题的行为与数据语义。

## 品牌约束

- 显示名称固定为“肥鱼记账”，只通过 `@string/app_name` 暴露；Manifest 不写死中文。
- 图标为纯矢量资源，自适应图标（API 26+）与 pre-26 矢量回退同名同形，避免位图与网络资源。
- 图形内容限制在自适应图标 66dp 安全圆内（viewport 108 的 21..87 范围），保证圆形/方形/水滴遮罩下都不被裁掉关键特征。
- 图标前景不得包含 `<text`、`¥`、`$`、`pig`、`coin`、`calculator` 等 token（沿用 `BrandIdentityContractTest` 的隐私与品牌边界）。

## 图标设计（大肥鱼）

- 底色：暖薄荷水色 `#CDEFF4`（清水），保证与奶白鱼身有足够明度差。
- 鱼身：横向胖椭圆，`#FFF9F0` 奶白，圆润无锐角，占据视觉中心。
- 尾鳍：右侧两瓣扇形（用 path 绘制），略小于鱼身，形成“胖而不钝”的剪影。
- 背鳍/腹鳍：上下各一枚小三角弧片，强化鱼的身份。
- 眼睛：深青 `#165E5A` 圆点 + 一点高光，保持中性表情。
- 腮红：珊瑚 `#F27D73` 小圆，唯一的暖色点缀，与皮肤强调色同源。
- 整体不画鳞片线条：小尺寸下会糊成噪点，采用纯色块更耐看。

## 皮肤设计（蓝色肥鱼）

定位：比“清透薄荷”更水感、比“小票账本”更现代；靠圆角、留白与单一强调色表达“简约”，只在一处放大肥鱼元素。

| primary | `#1F7A8C` | 湖水青，按钮与选中态 |
| onPrimary | `#FFFFFF` | |

| onPrimaryContainer | `#0C3F49` | |
| background | `#F5FBFC` | 极浅水底 |

肥鱼元素只出现在首页顶部标题行右侧（24dp 小肥鱼 + 无文字），其余页面保持纯粹的排版与配色，避免“到处贴吉祥物”的廉价感。

## 兼容与不改动

- 不改数据库、备份格式（备份校验按 `ThemeStyle.entries` 名称，新增枚举值自动兼容）。
- 不改通知识别、无障碍、截图 OCR、权限、依赖。
- 默认主题仍是 `CLEAR_MINT`，已有用户偏好不受影响。
- 不改服务名称、快捷设置磁贴名称。

## 验收

- `BrandIdentityContractTest`：`app_name` 为“肥鱼记账”，Manifest 引用资源，图标资源存在且无禁用 token。
- JVM 全量测试通过；`assembleDebug` 成功；`aapt2 dump badging` 显示 `application-label:'肥鱼记账'`。
- 设置页出现第四个外观选项“蓝色肥鱼”，选中后首页出现小肥鱼且配色切到湖水青。
